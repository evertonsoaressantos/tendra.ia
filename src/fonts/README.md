# Fontes da interface

Os arquivos WOFF2 são os subconjuntos Latin das famílias Space Grotesk,
IBM Plex Sans e IBM Plex Mono usados pelo design system. Foram copiados dos
artefatos gerados por `next/font/google` antes da troca para `next/font/local`,
preservando as mesmas fontes exibidas pela aplicação. As respectivas licenças
SIL Open Font License estão em `licenses/` e vêm dos diretórios oficiais
[`ofl`](https://github.com/google/fonts/tree/main/ofl) do Google Fonts.
